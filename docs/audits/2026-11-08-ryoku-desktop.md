# Audit Ryoku untuk desktop ConstOS

Audit sumber pada 8 November 2026 membandingkan Ryoku v1.0.7 (`f7197d72d`), ConstOS `7d14cf90`, dan helper Linux dari monorepo Const Harness `d77752fb`. Pemetaan mencakup 8.973 path terlacak Ryoku. Pembacaan difokuskan pada entry point sesi, paket, konfigurasi, dan backend yang berkaitan dengan desktop. Hasil ini adalah bukti sumber. Tampilan, performa, serta perilaku Wayland masih memerlukan pengujian pada target. [Snapshot Ryoku](https://github.com/Ryoku-dev/ryoku/tree/f7197d72de8a21e44b0bea922bdd915f28f6b327)

## Gap pada implementasi ConstOS

- **Desktop terpasang dan cutover.** `constos-desktop` memasang Hyprland, Waybar, Wofi, Mako, Foot, Thunar, Firefox, Mousepad, Ristretto, Evince, dan File Roller. Konfigurasi awal di `/etc/skel` disalin saat akun dibuat. Update paket ke `/etc/skel` tidak membawa default baru ke home yang sudah ada. Siapkan migrasi dengan backup sebelum mengganti panel atau shortcut pada akun yang sudah terpasang. [Staging desktop](../../desktop/install.sh) · [Paket desktop](../../packages/constos-desktop/PKGBUILD)
- **Katalog dan identitas aplikasi.** Welcome menawarkan LibreOffice, VLC, LocalSend, dan KeePassXC. Backend membatasi instalasi pada ref `x86_64/stable` Flathub per pengguna, sementara inventaris membaca ID aplikasi dari semua instalasi dan tidak membedakan branch maupun origin. Salinan system-wide atau branch lain bisa ditampilkan sebagai sudah terpasang sehingga tombol Install terkunci. Samakan identitas dan scope sebelum katalog dipakai sebagai Library. [Backend katalog](../../desktop/welcome/catalog.py) · [UI Welcome](../../desktop/welcome/welcome.py)
- **Harness dan batas Wayland.** Resep paket lokal baru memasang launcher yang menunjuk ke binary di `/opt`. Helper upstream menawarkan aksi semantik AT-SPI pada Wayland. Capture visual serta input pointer/keyboard melalui portal bergantung pada kemampuan yang benar-benar tersedia di versi Hyprland/XDPH yang dikirim. Spesifikasi portal menjelaskan pemberian perangkat dan EIS; catat hasil probe backend sebelum menetapkan cakupan kontrol. [Resep Harness](../../packages/const-harness/PKGBUILD) · [RemoteDesktop portal](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.RemoteDesktop.html)

## Dampak pada rencana

Fondasi CachyOS, UEFI, Hyprland, Calamares, Rust, dan portal tetap dipakai. Perubahan utamanya ada pada urutan pengiriman dan pemilik fitur. Validasi build Cage terbaru, lalu buktikan satu launcher Liquid Glass dan kontrol audio bersama Const Hub sebelum menambah dock, widget, dan Island. Const Store dapat dikembangkan dari katalog GTK yang ada. Kontrak widget bawaan bisa diuji tanpa Harness, lalu digunakan untuk draft widget setelah paket Harness berjalan. Computer use tetap memakai penerimaan terpisah. Urutan dan gerbang lengkap ada di [roadmap](../../implementation_plan.md#backlog-pertama-yang-bisa-dieksekusi).
